# Joystick Timer

A countdown timer for Arduino, set and started with a joystick.

The timer runs on an Arduino Uno. The remaining time appears on a 4-digit TM1637 display as minutes and seconds, and a joystick module sets the duration and starts the countdown.

## How it works

1. **Setting**: the display shows minutes on the left and seconds on the right. The selected pair flashes. Pushing the joystick left or right switches between minutes and seconds, pushing it up or down changes the value (minutes wrap at 99, seconds at 59). Values change at most once every 200 ms.
2. **Start**: a click on the joystick button starts the countdown. The colon between the pairs blinks every second while the timer runs.
3. **Countdown**: the seconds and minutes decrease every second until they reach `00:00`.
4. **End**: both pairs flash when the timer reaches zero.
5. **Reset**: a click on the joystick button stops the flashing and goes back to the setting mode.

The main loop runs at 60 iterations per second. It polls the joystick, then updates the timer state and the display.

## Tech stack

| Layer | Technologies |
| --- | --- |
| Firmware | C++, Arduino framework |
| Hardware | Arduino Uno, analog joystick module with a push button, TM1637 4-digit display |
| Libraries | TM1637 (bundled in `lib/`, LGPL 2.1 or later) |
| Tooling | PlatformIO (`atmelavr` platform), CMake (CLion integration) |

## Repository structure

```
.
├── lib/
│   └── TM1637/       Driver for the TM1637 display
├── src/
│   ├── joystick/     Joystick reading: direction, button state, input rate limit
│   ├── screen/       Display wrapper: two 2-digit values and the colon
│   ├── timer/        Timer state machine: setting, running, finished
│   ├── config.hpp    Pin numbers and refresh rate
│   └── main.cpp      Setup and main loop
├── CMakeLists.txt    Generated by PlatformIO for CLion
└── platformio.ini    PlatformIO environment
```

Each component in `src/` is a class declared in a `.hpp` file and defined in a `.cpp` file of the same name. `CMakeLists.txt` is generated by PlatformIO and should not be edited.

## Prerequisites

- An Arduino Uno
- A joystick module with a push button
- A TM1637 4-digit display
- [PlatformIO](https://platformio.org/) (CLI or IDE extension)

Wiring, as defined in [`src/config.hpp`](src/config.hpp):

| Component | Signal | Arduino pin |
| --- | --- | --- |
| Joystick | Button | `2` |
| Joystick | X axis | `A1` |
| Joystick | Y axis | `A0` |
| TM1637 | DIO | `3` |
| TM1637 | CLK | `4` |

## Installation

```bash
git clone git@github.com:maxencebonamy/Joystick-Timer.git
cd Joystick-Timer
```

## Configuration

The project has no environment file. Settings are constants in [`src/config.hpp`](src/config.hpp); edit them and upload the firmware again.

| Constant | Description | Example |
| --- | --- | --- |
| `pin::joystickButton` | Digital pin of the joystick button | `2` |
| `pin::joystickX` | Analog pin of the joystick X axis | `A1` |
| `pin::joystickY` | Analog pin of the joystick Y axis | `A0` |
| `pin::screenDIO` | Data pin of the display | `3` |
| `pin::screenCLK` | Clock pin of the display | `4` |
| `FPS` | Iterations of the main loop per second | `60` |

## Running locally

Connect the board over USB, then build and upload the firmware.

```bash
pio run --target upload
```

The timer starts at `00:00` with the seconds selected.

## Useful scripts

| Command | Effect |
| --- | --- |
| `pio run` | Build the firmware |
| `pio run --target upload` | Build and upload the firmware to the board |
| `pio run --target clean` | Remove build files |
